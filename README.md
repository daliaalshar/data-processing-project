# 📱 Social Media & Mental Health Data Analysis

## Overview

This project explores the relationship between **social media usage** and **mental health indicators** using a dataset of **8,000 survey responses**. The project covers the complete data processing pipeline, including data quality assessment, data cleaning, exploratory data analysis (EDA), feature engineering, dimensionality reduction, and statistical analysis.

## Dataset

* **Dataset:** Social Media & Mental Health
* **Records:** 8,000
* **Features:** 15 original features
* **Domain:** Mental Health & Social Media Analytics

## Objectives

* Assess data quality.
* Clean and preprocess the dataset.
* Explore relationships between social media behavior and mental health.
* Engineer meaningful new features.
* Prepare the dataset for machine learning and advanced analysis.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Data Preprocessing

The project included:

* Data quality assessment
* Missing value handling
* Duplicate detection
* Data type correction
* Outlier detection using the IQR method
* Feature scaling with StandardScaler
* Label Encoding
* One-Hot Encoding

## Feature Engineering

Three new features were created:

* **Mental_Health_Risk_Score**
* **Sleep_Screen_Ratio**
* **High_Risk_Flag**

Additional preprocessing included:

* Feature Selection
* Principal Component Analysis (PCA)

## Exploratory Data Analysis (EDA)

The analysis included:

* Summary statistics
* Histograms
* Count plots
* Correlation heatmap
* Boxplots
* GroupBy analysis
* Pivot tables

## Key Findings

* Higher daily screen time is associated with increased anxiety and depression scores.
* Sleep duration acts as a protective factor against mental health risks.
* Different social media platforms show varying average mental health risk levels.
* Social comparison is linked to higher mental health risk.
* Approximately **30%** of participants were classified as high-risk users.
